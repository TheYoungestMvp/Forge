# Public Sans

The Forge workspace uses the Latin variable Public Sans font, with weights 400–700.

- Font file: PublicSans-Latin-Variable.woff2 (26,832 bytes).
- Downloaded on 2026-10-09 from the [Google Fonts v21 asset](https://fonts.gstatic.com/s/publicsans/v21/ijwRs572Xtc6ZYQws9YVwnNGfJ4.woff2).
- [Upstream source and license](https://github.com/google/fonts/tree/main/ofl/publicsans); the license is included in OFL.txt.

Next.js serves this asset with the application. No runtime font CDN request is needed. Chinese text uses the configured system fallbacks.
